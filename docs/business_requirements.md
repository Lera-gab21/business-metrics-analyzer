# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Цель приложения
Автоматизировать расчёт и визуализацию ключевых показателей эффективности (KPI) предприятия, чтобы сократить время подготовки аналитических отчётов.

## 2. Заинтересованные стороны
- Руководитель отдела: получает сводку KPI.
- Бизнес-аналитик: загружает данные и формирует отчёты.

## 3. Бизнес-требования
- Приложение рассчитывает рентабельность, среднюю выручку и динамику выручки по месяцам.
- Приложение строит график динамики выручки.
- Результаты выводятся в понятном для аналитика виде.

## 4. Функциональные требования
| № | Требование | Приоритет |
|---|---|---|
| FR-1 | Загрузка данных о выручке и затратах | Высокий |
| FR-2 | Расчёт рентабельности в процентах | Высокий |
| FR-3 | Расчёт средней выручки за период | Средний |
| FR-4 | Построение графика выручки (matplotlib) | Средний |

## 5. Нефункциональные требования
- Язык: Python 3.10+.
- Запуск одной командой: `python main.py`.
- Зависимости фиксируются в `requirements.txt`.
- Код хранится в Git-репозитории.

## 6. Ограничения
Учебный проект, данные демонстрационные.
